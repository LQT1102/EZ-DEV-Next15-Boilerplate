### This project includes:

* Multi-language support with Next.js and next-intl, supporting both client-side and server-side rendering.
* UI library usage of tailwindcss, daisyui, and next-themes, supporting multiple themes.
* Additionally, it utilizes react-hook-form, yup, and classnames.
